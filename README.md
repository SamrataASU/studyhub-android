# StudyHub for Android

Turns your Canvas calendar feed into a clean deadline tracker: countdowns, a Monday–Sunday progress ring,
reminders before each deadline, home-screen widgets, a focus timer, and daily finance news from Google News.

Everything stays on your phone. The app only downloads your Canvas calendar (from the link you paste) and public headlines.

## Install a test version
Open the **Releases** page of this repository, download the newest **StudyHub.apk** on your Android phone,
allow "Install unknown apps" when asked, and tap **Install**. On first launch, enter your name and your Canvas
**Calendar Feed** link (Canvas → Calendar → Calendar Feed).

## Build it yourself
Open the folder in Android Studio and press Run. See `PLAY-STORE-GUIDE.md` for publishing on Google Play.
